# Go Design Patterns

This collection turns common design-pattern interview questions into small Go exercises. Work through the folders in order: read the task, implement `task.go`, then run `go test` from that folder. The starter implementation is intentionally incomplete, so its tests fail until you solve the exercise.

Reference implementations live in each `solution/` folder. Verify one with `go test ./solution` from its exercise directory. Read the solution README only after attempting the problem; it explains both the pattern and the Go-specific trade-offs.
